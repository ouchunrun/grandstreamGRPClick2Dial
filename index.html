Grandstream GRP Click2Dial Demo

    Grandstream GRP Click2Dial is a lightweight web browser extension that seamlessly integrates with Grandstream GRP260x series and GRP260x Lite devices.
    It allows users to log in via the device's IP or MAC address, enabling one-click dialing, screen sharing, software annotation, and file transfer directly from their computers.
    This plugin reduces manual operations on physical phones, significantly enhancing communication efficiency and convenience.

    Key Features:
    1. Directly initiate phone calls by selecting contact-related strings on webpages within the browser.
    2. Easily share screens during calls for remote presentations or collaboration.
    3. Annotate in various styles while screen sharing.
    4. Conveniently transfer files during calls to improve communication efficiency.
    5. Receive real-time incoming call notifications on the computer for prompt handling.

    Important Information:
    - GRP260x firmware versions below 1.0.5.25 are not supported.
    - GRP260x firmware versions 1.0.5.25 through 1.0.7.5 support only basic dialing functionality.
    - GRP260x firmware versions 1.0.7.33 and later support the full range of sharing features.
    - GRP260x Lite firmware versions 1.0.1.x and later are supported.

    Requirements and Notes

    1. Set “Web Access Mode” to “HTTP” or “Both HTTP and HTTPS”.
    2. Enable “Click-To-Dial Feature”.
    3. Enable “Enable User Web Access”.
    4. Logging in with the default password is not supported.
    5. This plugin supports GRP260x and GRP260x Lite series phones only. Other phone models cannot log in to the plugin.
    6. Only one plugin can be logged in on each device at a time. Simultaneous login to multiple plugins is not supported.
    7. Direct IP calling is supported. Enable “Enable Direct IP Call” before using this feature.
